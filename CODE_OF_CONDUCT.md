# Code of conduct

Dioptra is a small project with a simple rule: be precise and be kind.

- Discuss ideas and evidence, not people.
- Assume good faith; ask before concluding.
- No harassment, discrimination or personal attacks, anywhere the project is discussed.
- Maintainers may edit, remove or lock contributions that break these rules and may ban
  repeat offenders.

Report problems privately to the maintainer through GitHub (open a security advisory or
contact the profile listed on the repository). Reports are handled confidentially.
