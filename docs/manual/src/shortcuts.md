# Keyboard shortcuts

Every command is in the **command palette**: press Ctrl-K (⌘-K on a Mac), type a few
letters of what you want, press Enter. The palette shows each command's shortcut, so it is
also the way to learn them. **F1** shows this list inside the app.

On macOS read ⌘ for Ctrl and ⌥ (Option) for Alt.

## File

| Command | Shortcut |
|---|---|
| New project | Ctrl-Alt-N |
| New table | Ctrl-Alt-T |
| Open | Ctrl-O |
| Save | Ctrl-S |
| Save as | Ctrl-Shift-S |
| Import file (CSV, TSV, XLSX, XLS, ODS, PZFX) | Ctrl-I |
| Paste as new table | Ctrl-Shift-V |
| Export table (CSV, TSV, XLSX) | Ctrl-Shift-E |

## Edit

| Command | Shortcut |
|---|---|
| Undo | Ctrl-Z |
| Redo | Ctrl-Shift-Z or Ctrl-Y |
| Cut, copy, paste | Ctrl-X, Ctrl-C, Ctrl-V |
| Edit cell | F2 or Enter |
| Fill down | Ctrl-D |
| Exclude or include the selected values | Ctrl-E |
| Clear | Delete or Backspace |
| Select all | Ctrl-A |
| Recompute everything | F9 |

## Insert

| Command | Shortcut |

## Moving in the grid

| Key | Moves |
|---|---|
| Arrow keys | One cell |
| Shift-arrow | Extends the selection |
| Tab, Shift-Tab | Right, left; wraps to the next or previous row |
| Enter, Shift-Enter | Down, up (after typing, commits and moves) |
| Home, End | Start, end of the row |
| Ctrl-Home, Ctrl-End | First cell, last cell of the table |
| Page Up, Page Down | One screen |
| Escape | Cancels an edit |

While typing in a cell, the arrow keys commit the value and move, as in a spreadsheet.
In the formula bar, Enter commits and Escape cancels.
