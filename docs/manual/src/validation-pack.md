# Validation pack

The validation pack for Dioptra Lab is kept with the source, for QA readers:
[docs/validation](https://github.com/ZahakJ/dioptra/tree/main/docs/validation). It holds
the Part 11 and Annex 11 compliance matrix, requirements traceability, IQ and OQ protocols,
PQ guidance, change control and the supplier assessment. The automated OQ runs from
*Records → Run OQ…*.
