# Launch

Twelve weeks, 3–5 h a week, owner's tasks only. Week 1 starts Monday 19 October 2026;
the review is Sunday 10 January 2027.

| File | Use |
|---|---|
| [hardware-test.md](hardware-test.md) | Windows and macOS checklists, 45 min per machine |
| [posts.md](posts.md) | Launch drafts: r/labrats, r/bioinformatics, Show HN, Bluesky, founding member |
| [user-calls.md](user-calls.md) | Call script, note template, where to find 10 users, DM text |
| [core-facilities.md](core-facilities.md) | Pilot email, follow-up, finding 50 managers, CSV |
| [metrics.md](metrics.md) | Kill check, sources, weekly routine, log |
| `../../scripts/downloads.sh` | Download counts per release and platform → `downloads.csv` |

Every Sunday: the 10-minute routine in [metrics.md](metrics.md). It is counted in the
hours below.

## Calendar

| Wk | Dates | Owner's tasks | h |
|---|---|---|---|
| 1 | 19–25 Oct | Issue a trial key. [hardware-test.md](hardware-test.md): Windows 11 (msi, exe), Windows 10 (msi). File failures. | 3 |
| 2 | 26 Oct–1 Nov | Hardware test: Mac Apple silicon on macOS 15+, on 13 or 14, and Intel. File failures. | 3 |
| 3 | 2–8 Nov | Re-test what failed. Read the subreddit rules. Finalise [posts.md](posts.md): version, numbers, screenshots, alt text. Set up Bluesky if needed. | 3 |
| 4 | 9–15 Nov | **Launch.** Tue: r/labrats and Bluesky, then answer for 6 h. Wed: Show HN, answer for 3 h. Thu: r/bioinformatics. List every commenter with a use case for calls. | 6 |
| 5 | 16–22 Nov | Send 30 asks ([user-calls.md](user-calls.md)). Hold 5 calls. Notes the same day. | 4 |
| 6 | 23–29 Nov | Hold 5 calls (no US calls Thu–Fri, Thanksgiving). Count the signals; write the top 3 problems. | 4 |
| 7 | 30 Nov–6 Dec | Paddle seller verification; buy one key in the sandbox, activate it in the app. Collect 60–70 core rows ([core-facilities.md](core-facilities.md)). | 5 |
| 8 | 7–13 Dec | **Paid launch**: founding-member post ([posts.md](posts.md)), one real purchase end to end. Send the first 25 core emails. | 5 |
| 9 | 14–20 Dec | Send the other 25 core emails. Follow up the first 25. Issue pilot keys the same day as a yes. | 5 |
| 10 | 21–27 Dec | Follow up the second 25. Answer replies. | 2 |
| 11 | 28 Dec–3 Jan | Answer replies. Check in with pilots. | 1 |
| 12 | 4–10 Jan | Follow up December replies "after the holidays". Sun: kill check in [metrics.md](metrics.md); write the one-line verdict. | 3 |

Core emails start in week 8 instead of 9 because weeks 10–11 fall over the holidays, when
facility managers do not answer.

## Kill criteria (week 12)

Stop if downloads < 3,000, paying seats < 30, or no site-license pilot.
