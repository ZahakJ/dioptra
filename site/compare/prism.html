Compare / GraphPad Prism

Dioptra vs GraphPad Prism

Dioptra is a free, open-source alternative to GraphPad Prism for Linux, Windows and macOS. It covers the common Prism work: tables, t tests, ANOVA, curve fitting, survival and publication graphs. Prism has decades of polish and a larger analysis library; Dioptra is free, runs on Linux, and puts effect sizes and formulas in the base product.

02 In short

Which to use

Prism is the better choice when

  • you need an analysis Dioptra does not have, such as mixed-effects models, three-way ANOVA, multiple or logistic regression;
  • your lab's templates, methods and years of files live in Prism and work well;
  • you want commercial support and GraphPad's statistics guides at hand.

Dioptra is the better choice when

  • you need a free GraphPad Prism alternative, for a course, a thesis, or a lab whose license was not renewed;
  • you work on Linux, where Prism does not run;
  • you want effect sizes, formulas and assumption checks without a higher plan;
  • you want an open file you can inspect, diff and re-run from the command line.

Moving from Prism

Open a .pzfx or .prism file and Dioptra reads its data tables, with replicates, row titles and exclusions. Analyses and graphs are rebuilt in Dioptra: Prism encrypts those parts of its files. The table kinds have the same names as Prism's, so the layout carries over. Reading Prism files is free and stays free.

03 Prism on Linux

Running Prism work on Linux

GraphPad does not make Prism for Linux and does not support it under Wine [2]. Dioptra is built and tested on Linux first, and ships an AppImage for any distribution, a .deb for Debian and Ubuntu and an .rpm for Fedora and openSUSE. The same project file and the same exported figure come out byte for byte on Windows and macOS, so a Linux user and a Mac user in the same lab can share files.
